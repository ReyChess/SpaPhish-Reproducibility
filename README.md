# SpaPhish Reproducibility Package

Reproducibility artifacts for **Interpretable Spanish Phishing Detection Using a Sparse Hybrid Representation and Direct Maximal Association Rules**.

This repository packages the experimental evidence used in the SpaPhish study: discretized representations, fixed folds, cross-validation outputs, feature/scoring ablations, negative-evidence and veto sensitivity, template-grouped validation, strict temporal validation, progressive updating and rule-evolution analysis, complexity summaries, and paired statistical validation.

## JISA 2026 evidence

The [JISA 2026 evidence](experiments/jisa_revision_2026/README.md) documents the 35-indicator stratified, grouped and retrospective chronological evaluations, training-only priors, prior sensitivity, and rule-level explanations. The historical 45-indicator experiments remain documented below.

## Dataset

The authoritative raw SpaPhish dataset is distributed through **Mendeley Data, version 5**, DOI `10.17632/hz2d6gz7pc.5`. This repository contains the derived transactional/discretized representations used by the experiments; it does not replace the raw-data distribution.

Class encoding used throughout the artifacts:

- `77` — legitimate
- `78` — phishing

## Quick verification

The fastest way to verify that the repository contains the expected core results is:

```bash
python verify_package.py
```

Expected output includes:

```text
VERIFY: OK
Temporal best sigma: 0.04
Held-out 2025 DMC-AC-P accuracy: 0.7690802348
Held-out 2025 phishing recall: 0.7612293144
Rule evolution (phishing): 31 persistent / 120 emerging / 72 disappearing
Recovered false negatives: 27/42 exactly covered by new rules
```

These checks validate stored experimental outputs; they are not a substitute for re-running every computational campaign.

To reproduce the main 10-fold computational pipeline from source rather than only verify stored summaries, run `python scripts/reproduce_main_10fold.py`.

## Main reproducible checkpoints

1. **Strict temporal selection.** Support is selected on 2024 data only; `sigma = 0.04` is selected before the final 2025 test.
2. **Held-out 2025 performance.** DMC-AC-P reaches approximately `0.7691` accuracy and `0.7612` phishing recall. The PN variant changes one prediction beneficially.
3. **Progressive update.** After observing the earliest 20% of 2025, the phishing rule base changes from 103 historical positive rules to 151 updated positive rules: **31 persist, 120 emerge, and 72 disappear** (Jaccard ≈ `0.139`).
4. **Recovered attacks.** Among 42 recovered historical false negatives, 27 are exactly covered by at least one newly emerged phishing rule; all 42 are exact-covered or one item away from a new phishing rule.

## Re-execution status

This repository now includes the **exact historical core sources** used by the main SpaPhish experiment: the direct-maximal CAR miner, the DMC-AC/M4d classifier, and the stratified 10-fold generator. Precompiled binaries and transient logs remain excluded so that builds are local and auditable.

The strongest reproducibility check is:

```bash
python scripts/reproduce_main_10fold.py
```

The script compiles the historical sources, uses the archived canonical folds/training sets, regenerates the ten rule files at `sigma=0.04`, requires byte-level SHA-256 identity with the stored `ReglasDataset*.dat` files, and reruns the classifier. Expected final lines are:

```text
REPRODUCE: OK
Rules regenerated exactly: 10/10 folds
Main 10-fold average accuracy: 88.2424%
Canonical folds: archived experimental folds (not regenerated by DivideEn10)
```

The historical `DivideEn10` source is also included, but it calls `srand(time(NULL))`; therefore repeated execution does not recreate the exact published partition. For numerical reproduction, the archived folds are authoritative. `DivideEn10` is retained to document how the stratified folds were originally produced.

Python analysis/orchestration scripts are retained and obvious `/mnt/data/...` paths have been replaced with repository-relative paths where the required inputs are present. Some experiment folders remain historical snapshots containing generated `.dat`, rule, prediction, and summary files because they form part of the evidence trail used by the manuscript.

### Build only

On Linux/macOS or Windows with GNU Make/MinGW:

```bash
make
```

This builds into the ignored `build/` directory. The historical miner uses SSE4.2 (`-msse4.2`).

For Python analyses:

```bash
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Temporal and rule-evolution artifacts

The most useful files for inspecting temporal restructuring are:

```text
experiments/spaphish_temporal_validation_results/spaphish_temporal_validation/
experiments/spaphish_rule_evolution_20_analysis/rule_evolution_all_positive.csv
experiments/spaphish_rule_evolution_20_analysis/rule_turnover_summary.csv
experiments/spaphish_rule_evolution_20_analysis/recovered_fn_rule_coverage.csv
experiments/spaphish_rule_evolution_20_analysis/new_phishing_rules_covering_recovered_fn.csv
```

The `rule_evolution_all_positive.csv` table contains the exact rule identities and their temporal status, allowing persistent, emerging, and disappearing direct maximal CARs to be inspected rather than inferred from aggregate counts.

## Statistical validation

`statistical_validation/` contains aligned out-of-fold predictions plus the paired McNemar-Holm and stratified-bootstrap results used for statistical comparisons.

## Integrity

`SHA256SUMS.txt` contains SHA-256 checksums for all tracked files except the checksum file itself. On Linux/macOS it can be checked with:

```bash
sha256sum -c SHA256SUMS.txt
```

The cross-platform `verify_package.py` script checks the principal stored results and required files.

## Scope note

This repository represents the **SpaPhish study itself**. The later Auto-DMC-AC user-data/deployment run is intentionally excluded so that the evidence from the original study is not mixed with subsequent experiments.
